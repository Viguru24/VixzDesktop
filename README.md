# 🎬 Vixz Desktop

A modern, high-performance **Glassmorphic YouTube Desktop Client & AI Copilot for Windows 10/11**, built with **.NET 9 & WPF (WebView2)**.

---

## ✨ Features

- **🤖 Built-in AI Copilot & Voice Assistant**:
  - *"Play the latest Benny Johnson video"* / *"Play Tucker Carlson today"*
  - *"Summarise this video"* (Generates 3-sentence TL;DR, Key Takeaways, and Interactive Clickable Timestamp Chapters)
  - Natural Language Controls: *"Skip 30 seconds"*, *"Set sleep timer for 25 mins"*
- **🛡️ Ad-Free & In-Video Sponsor Skipping**:
  - Full SponsorBlock integration that automatically skips in-video sponsorships, intros, and self-promotions with frame accuracy.
- **📥 One-Click High Quality Video Downloader**:
  - Download 1080p MP4 videos directly to your Downloads/Videos folder with real-time progress.
- **⧉ Always-On-Top Pop-out Mini Player**:
  - Floating PiP window with custom window controls and instant docking.
- **📸 Smart Screenshot Capture**:
  - Dedicated screenshot button (`S`) with customizable album destination folders.
- **🌙 Sleep Timer**:
  - Smooth fade-out and auto-pause with quick presets (15m, 30m, 45m, 60m).
- **🎨 Ultra-Rich Dark Glassmorphism UI**:
  - High-contrast typography, gold accents, smooth animations, and clean Windows window chrome.

## ⌨️ Keyboard Shortcuts

| Key | Action |
| --- | --- |
| `Space` / `K` | Play / Pause |
| `Left` / `Right` | Seek -5s / +5s |
| `J` / `L` | Seek -10s / +10s |
| `M` | Mute / Unmute |
| `S` | Capture Screenshot |
| `D` | Download Current Video (MP4) |
| `N` | Play Next Video |
| `F` | Toggle Fullscreen |
| `T` | Pin Window Always-on-Top |
| `F12` | Open Developer Tools |

## 🚀 Quick Start & Development

### Prerequisites
- Windows 10 or 11 (64-bit)
- [.NET 9.0 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)
- [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)

### Build & Run
```powershell
# Clone the repository
git clone https://github.com/Viguru24/VixzDesktop.git
cd VixzDesktop

# Build and Run
dotnet run --project src/VixzDesktop
```

Or simply double-click `Launch_Vixz.bat`.
